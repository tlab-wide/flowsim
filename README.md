Flowsim is written in <strong>pure Python</strong> within <strong>1500</strong> LoC.
The purpose is to enable researchers to fast-prototype, simulate, and test CDA algorithms and functions. 
By implementing the desired modules and define flow between them, users can create custom vehicle types very easily.
